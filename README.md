Company Profile SHOWROOMKU

Website ini merupakan company profile dari PT SHOWROOMKU. 
mencakup halaman Home, About, Main Content, Contact & Footer

Website bersifat statis dan belum bisa di deploy karena ini merupakan mini project dari tugas BSO

- Halaman Home berisi nama web yaitu SHOWROOMKU, deskripsi/pengenalan singkat dan nav bar
- Halaman About berisi informasi mengenai bisnis, latar belakang, visi misi, dan informasi relevan lainnya
- Halaman Main Content berisi bagian utama yaitu apa saja yang di jual oleh PT SHOWROOMKU
- Halaman Content & Footer berisi informasi kontak/ media sosial dari website SHOWROOMKU

Website ini dibuat menggunakan bahasa HTML, CSS, dan Javascript dasar
